# Thai Villas

Villa rentals in Thailand (Phuket first): daily and monthly/long stay, plus VIP services
(yachts, helicopters, supercars, superbikes, concierge). Static site on GitHub Pages.

## Build
Pages are generated by Python scripts in `tools/thai/` from the reference design and the data in `data/`:

- `data/villas.json` — villas (currently SAMPLE listings, prices "on request")
- `data/areas.json` — destinations and Phuket beach areas
- `data/vip.json` — VIP service categories
- `tools/thai/thv.py` — shared shell: brand, contacts, nav, mega-menu, footer, villa cards

```
python3 -I tools/thai/build_all.py --base /thaivillas   # GitHub Pages project URL
python3 -I tools/thai/build_all.py                      # custom domain / local
```

Placeholders to replace in `tools/thai/thv.py` and `thb-enquiry.js`: WhatsApp `66000000000`,
phone `+66 00 000 0000`, email `hello@thaivillas.example`. Site is `noindex` until launch.
