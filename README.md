# Thai Villas

Static site for a villa rental business in Thailand (Phuket, Koh Samui, Pattaya, Bangkok, Krabi, Chiang Mai).
Hosted on GitHub Pages. Plain HTML + Tailwind CDN, no build step.

- `index.html` — home
- `property-rental/` — catalog with filters (`?location=`, `?beds=`, `?period=`, `?amenity=`)
- `villas/{area}/` — area pages, `villa/{slug}/` — villa pages
- `data/villas.json` — villa data (currently 6 demo listings)

Placeholders to replace: WhatsApp `66000000000`, phone `+66 00 000 0000`, email `hello@thaivillas.example`,
demo villas and their photos. Site is `noindex` until launch.
