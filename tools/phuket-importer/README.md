# Phuket Importer

Локальная программа (клон `balivillahub-importer`), которая скачивает **весь** контент с:

- `getyourphuket.com/en/` — аренда и продажа, все объекты;
- `indreamsphuket.ru` — наши проекты;
- или любого другого сайта (вставить адрес).

Сайты качает ваш компьютер, поэтому облачные ограничения сети на него не действуют.

## Что делает

1. Находит все страницы: `robots.txt` → `sitemap.xml` (включая вложенные и `.gz`) + обход всех внутренних ссылок,
   в том числе ссылок, спрятанных в JS/JSON (сайты на Next.js/Nuxt).
2. Для каждой страницы определяет, объект это, страница-список или обычная страница (о компании, районы, статьи).
3. Из объекта извлекает: название, тип сделки (аренда / продажа / проект), тип объекта, район Пхукета,
   спальни, ванные, гости, этажи, площадь дома и участка, все цены с валютой и периодом (ночь / месяц / год / продажа),
   таблицу характеристик, удобства, полное описание, координаты (JSON-LD, Google Maps), видео (YouTube/Vimeo/mp4),
   документы (PDF-презентации, прайсы), хлебные крошки, JSON-LD и meta.
4. Скачивает **все фото в оригинальном размере**: `src`, `srcset`, lazy-load (`data-src`, `data-original` и др.),
   CSS-фоны, `og:image`, фото из JS-галерей. Превью WordPress (`-300x200`) и Tilda (`/-/resize/…`) заменяются
   на оригиналы, а если оригинал недоступен, скачивается версия, которая стоит на странице.
5. Логотипы, иконки и баннеры, которые повторяются на всех страницах, отбрасываются.
   Фото из блока «Похожие объекты» в галерею не попадают, но их адреса сохраняются в `relatedImages`.
6. Остальные страницы сайта тоже сохраняются (текст + фото), чтобы ничего не потерять.

Страницы сайта, `data/villas.json` и sitemap программа **не меняет**: она только создаёт папку в `imports/`.

## Запуск

Нужен Docker Desktop. Windows (PowerShell):

```powershell
cd <папка репозитория thaivillas>\tools\phuket-importer
.\run.ps1
```

macOS / Linux:

```bash
cd <папка репозитория thaivillas>/tools/phuket-importer && ./run.sh
```

Открыть http://localhost:8093, выбрать сайт и нажать **«Скачать весь сайт»**.

Без Docker (нужен Python 3.10+): `pip install requests`, затем

```bash
python app.py crawl getyourphuket
python app.py crawl indreams
python app.py single https://getyourphuket.com/en/<страница объекта>
```

Результат при запуске без Docker попадает в `/workspace/imports`, если не задать
`THAIVILLAS_WORKSPACE=<папка репозитория>`.

## Результат

```text
imports/getyourphuket-all-YYYYMMDD-HHMMSS/
  index.html               ← открыть в браузере: карточки всех объектов
  catalog.json             ← все объекты целиком
  thaivillas-import.json   ← объекты в формате нашего сайта (для заливки на сайт)
  pages.json               ← остальные страницы
  crawl-log.json           ← каждая обойдённая страница и как она классифицирована
  raw/                     ← сырой HTML всех страниц
  properties/<slug>/
    property.json  manifest.json  README.md  raw/page.html  photos/001.jpg…  docs/*.pdf
  pages/<slug>/
    page.json  manifest.json  README.md  raw/page.html  photos/
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `IMPORTER_DELAY` | `0.25` | пауза между запросами страниц, сек |
| `IMPORTER_PHOTO_WORKERS` | `6` | сколько фото качать параллельно |
| `IMPORTER_TIMEOUT` | `60` | таймаут запроса, сек |

Если объект попал в «другие страницы», его всё равно видно в `pages/` (с фото), а в `crawl-log.json`
указано, почему: в поле `reasons`. Отдельную страницу можно перекачать как объект кнопкой
«Скачать один объект по ссылке».
